Limitations


  • Five reactions. The headline statistics rest on n = 5 reactions (n = 3 at the larger basis, n = 4 for CCSD(T)). The 95 % bootstrap interval of the Skala-1.1 mean absolute error is 0.66 to 2.42 kcal/mol; differences between functionals of a few tenths of a kcal/mol are not resolved.
  • One geometry protocol. All headline energies are single points at B3LYP-D3(BJ) geometries. GFN2-xTB geometries were used only in the scout test, and Skala-1.1-relaxed geometries were not computed.
  • An unexplained ωB97M-V value. ωB97M-V underestimates the HCN → HNC barrier by 3.5 kcal/mol (and the HCN → HNC reaction energy by 2.7). We did not find the cause. It dominates the ωB97M-V mean absolute error: without HCN it is 0.46 instead of 1.08.
  • References. The five literature values of the headline set were checked in their sources (the H₂CO value from the abstract of the paper); the H₂CO value includes zero-point energy, which was corrected with a B3LYP harmonic zero-point difference (−4.99 kcal/mol) for every method. The CH₃NC value could not be verified and is in no statistic. Our CCSD(T) is unusable for H₂CO (unstable reference at the transition state).
  • No stability analysis of the DFT solutions. Convergence of each SCF was recorded, but no test whether a lower-energy solution exists. The Cl⁻ + CH₃Cl transition state with Skala-1.1 converged only with density fitting.
  • Skala-1.1 without D3 is the same SCF with the D3 energy removed, not a separate optimisation of the functional without D3.
  • Paths. The HCN path reference has 8 of 11 points; the H₂CO path is a failed path and supports no conclusion.
  • Timings come from one run on Colab-class hardware and are not a benchmark.
  • Not on this site: the text of the manuscript and any correspondence. This site is the data, code and views behind it.

How this site is made


The pages are plain HTML, CSS and JavaScript with no external libraries, fonts or services. tools/build_site.py rebuilds every page and JSON file from the CSV files in data/; tools/sync_sources.py copies the sources into this folder. The site stores nothing about you except your choice of light or dark theme, kept in your browser.
